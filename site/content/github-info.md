### Awesome Copilot Workflows

Eight community-contributed agentic workflows are available at [awesome-copilot.github.com/workflows](https://awesome-copilot.github.com/workflows/)—AI-powered automations that run coding agents inside GitHub Actions. Highlights:

- **Daily Issues Report** – auto-generates a daily summary of open issues on a schedule.
- **GitHub Relevance Check** – a slash command that evaluates whether an issue or PR is still relevant to the project.
- **GitHub Weekly Comment Sync** – finds stale code comments, makes text-only sync updates, and opens a draft PR when changes are needed.
